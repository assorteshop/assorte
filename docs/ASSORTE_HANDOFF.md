# ASSORTE — документ для нового чата (handoff)

Обновлено: 28 жовтня 2026. Вставьте этот файл в начало нового чата с Claude, чтобы не объяснять проект заново.

## 1. Что такое ASSORTE
Независимый украинский интернет-магазин **«Продумані деталі для кращих моментів»** (подпись бренда: «Більше, ніж просто речі ♡»). Продаёт отобранные полезные и красивые вещи. Это **отдельный проект**: он не связан с Talent Mates, MATE и VOLYA (другие репозитории, базы, домены, аккаунты). Ничего оттуда не использовать.

- Сайт: **https://assorte.com.ua** (боевой домен, индексация включена). Старый технический адрес `assorte.vercel.app` и `www` перенаправляются на основной.
- Язык сайта: украинский. Валюта: гривна. Общение с основателем: **русский**.
- Категории (6, в коде `src/lib/categories.ts`): `sport` Спорт і актив (приоритет №1), `tech` Tech і гаджети, `gifts` Подарунки, `style` Стиль і комфорт, `climate` Кліматична техніка, `auto` Авто і мото.
- Основатель — не программист. Любит **один шаг за сообщение**, простые формулировки, реальные проверки. Раздражается, когда задача разрастается лишним (так было с «блогом»: просили блог, а бриф превратился в большой спринт).

## 4. Стек и особенности
Next.js **16** (App Router, `cacheComponents` включён, `proxy.ts` вместо middleware), React 19, TypeScript, Tailwind 4, Supabase (Postgres, Auth, Storage), Vitest, Zod. Перед правками смотреть `node_modules/next/dist/docs/` (это не Next, который знают по памяти).
- Данные кэшируются через `'use cache'` + теги (`products`, `articles`, `banners`, `reviews`, `settings`); админские действия вызывают `updateTag`, поэтому правки видны сразу. Правки прямо в Supabase видны до минуты.
- Страницы, читающие `params`/`searchParams`/cookies, оборачиваются в `<Suspense>`.
- `sanitize-html` нельзя использовать с разбором CSS (вызывает `Math.random`, Next 16 это запрещает при пререндере); в `src/lib/article-html.ts` свой фильтр стилей.
- Команды: `npm run typecheck`, `lint`, `test` (Vitest), `build`. Локальный запуск без ключей Supabase показывает макетные заглушки.
- `src/lib/site.ts`: адрес сайта и **переключатель индексации** только по `NEXT_PUBLIC_SITE_URL`. Домен в коде не хардкодить. На `*.vercel.app` и preview сайт закрыт (`noindex`, `Disallow`).
- Денежные суммы: **целые гривны** (не копейки).

## 5. Что уже сделано (всё выложено на production)
**Витрина:** главная по утверждённому макету, слайдер «Популярні товари» (красная стрелка у заголовка + боковые стрелки), каталог и 6 категорий, поиск (`/search`, также поле в каталоге), «Новинки», страница **«Про нас»**.
**Карточка товара:** фото-галерея; название, короткое описание; цена и «Додати в кошик» в одной строке; под ценой звёзды и число отзывов; блок доставки (Нова пошта, Укрпошта) и оплаты (после получения; картой на сайте, знижка 5%); под фото **три закладки Опис / Характеристики / Відгуки**; «Читати більше» у длинного описания; варианты (**артикул**: товары с одним артикулом собираются в одну карточку, выбор «5 кг / 10 кг»; вариант необязателен).
**Корзина и заказы:** корзина в localStorage; оформление (Нова пошта или Укрпошта, оплата после получения; онлайн-оплата скрыта до LiqPay); цена и сумма считаются **в базе** (функция `create_order`), скидка 5% при оплате картой тоже; согласие с офертой под кнопкой; заказы и статусы в админке; Telegram-сообщение о каждом заказе.
**Отзывы:** покупатель пишет → статус «ожидает» → вы публикуете/скрываете/удаляете в админке; звёзды и счётчик только по опубликованным.
**Блог** (`/blog`, старые `/articles` → 301): статьи пишутся в **Claude chat** по инструкции `docs/claude-chat-article-prompt.md` как HTML (эталон `docs/reference/blog-article-reference.html`) и **вставляются в редактор без правок**. Редактор сам заполняет заголовок, адрес, анонс, SEO; даёт кнопки для фото-заглушек; `[[product:адреса]]` вставляет карточку товара; есть FAQ, источники, SEO-поля. Статья-лендинг: товары внизу, липкая кнопка «Купити» на телефоне, разметка Article/Breadcrumb/FAQ, canonical, Open Graph. Блоки внизу главной выбирают статью и показывают «Читати далі».
**Админка** (`/admin`): Товари (фото, редактор текста Ж/К/П, характеристики, артикул, порядок, публикация), Статті, Блоки на головній, Замовлення, Відгуки, **Контакти** (реквізити продавця, телефон, email, соцсети).
**Страницы условий:** Доставка і оплата, Повернення, Публічна оферта, Контакти (тексты в `src/lib/legal.ts`, дата редакции там же). Они показывают реквизиты только если они заполнены в админке «Контакти».
**SEO и домен:** `robots.txt`, `sitemap.xml` (~40 адресов), canonical, 301 со старых адресов, `www` → основной домен.

## 6. SQL: порядок и правило
Файлы в `supabase/` (применены основателем вручную в Supabase → SQL Editor): `schema.sql`, `seed.sql`, `migration-categories`, `-orders`, `-admin`, `-liqpay`, `-variants`, `-articles`, `-blog-a`, `-blog-b`, `-product-card`, `-reviews`, `-site-settings`. Файлы в `supabase/products/*` — тестовые товары (основатель уже удалил их и ведёт настоящий каталог, ~22 товара).
**Правило:** SQL только добавляет (ничего не удаляет), показывается основателю текстом, затем кладётся в буфер: `LC_ALL=en_US.UTF-8 pbcopy < файл.sql` (без этого кириллица портится). Функции с `security definer` пишутся с `set search_path = ''` и именами `public.*`. Новый код, читающий новые колонки, выкладывать **после** того, как основатель выполнил SQL.

## 7. Как мы работаем (правила основателя)
1. Работа в **отдельной ветке**, затем проверка (`typecheck`, `lint`, `test`, `build`) с реальным выводом.
2. SQL показать текстом и ждать «выполнил».
3. **Влить в `main` (= выложить на production) только по прямому разрешению**, после этого проверить живой сайт командами и пересказать результат.
4. Один шаг за сообщение при настройках во внешних сервисах (Vercel, Supabase, DNS).
5. Не выдумывать данные, не копировать чужие тексты и картинки, не подставлять чужие телефоны и реквизиты.
6. Не копировать статью со страницы браузера (ломается кодировка): копировать из Claude chat кнопкой «Copy».
7. Ветки `about-page`, `blog-v4`, `domain-switch`, `fix-encoding`, `indexing-closure`, `legal-pages`, `product-card`, `reviews-tabs` уже влиты в `main` (можно удалить).

## 8. Открытые вопросы и идеи (по важности)
1. **Мобильное меню:** на телефоне навигация в шапке скрыта и гамбургера нет (только значки поиска и кошика). Нужно добавить.
2. Основатель должен **заполнить реквизиты** в админке «Контакти» и дать **юристу прочитать** оферту, возврат и доставку. До этого настоящие продажи начинать нельзя.
3. Страница **«Політика конфіденційності»** (в оферте только раздел про данные).
4. **LiqPay**, когда будет кабинет: ключи в Vercel, адрес сайта указать в кабинете, проверить тестовую оплату (`LIQPAY_SANDBOX=1`). Код и скидка 5% готовы.
5. **Email-уведомления** о заказах (Resend, ключ + свой адрес на домене), сейчас работает только Telegram.
6. Дописать фото кота в блок «Досвід і експертиза» (основатель обещал прислать хорошие фото) и фоны для трёх блоков на главной.
7. Авто-теги `Product` и рейтинг в Google (JSON-LD) добавить, когда накопятся настоящие отзывы.
8. Мелочи: сердечко «в обране» ничего не делает; нет остатков товара; нет личного кабинета; удалять заказы в админке нельзя (только статус); отдельная база для разработки (сейчас одна на всё).
