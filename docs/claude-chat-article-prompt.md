# Інструкція для Claude chat: як писати статтю для блогу ASSORTE

Скопіюйте текст нижче в Claude chat (разом із темою статті) і прикріпіть файл `docs/reference/blog-article-reference.html` як зразок.

---

Напиши статтю для блогу інтернет-магазину ASSORTE українською мовою.

**Формат — рівно як у прикріпленому зразку `blog-article-reference.html`:** один HTML-фрагмент від `<article ...>` до `</article>`, з такими самими інлайн-стилями, кольорами (#B60016, #171717, #F6F4F1) і шрифтами (Manrope для заголовків, Inter для тексту). Я вставлю його в редактор сайту без змін.

Обовʼязково:
1. **SEO-коментар на самому початку**, як у зразку: рядки `URL: /blog/<адреса-латиницею>`, `Title:` (до 60 символів), `Meta description:` (120–160 символів). Сайт сам заповнить ними поля.
2. **Рівно один `<h1>`**: заголовок статті. Над ним — надпис-категорія (маленький червоний рядок), під ним — лід-абзац (2–3 речення, він піде в анонс).
3. Структура: блок «Коротко», розділи з мітками `01 · …`, `02 · …`, H2/H3, таблиці, блоки «Важливо», картки з великими цифрами, формула — як у зразку. Таблиці загортай у `<div style="overflow-x:auto;">`.
4. **Фото — заглушками**, як у зразку: блок «ФОТО N · опис» з пунктирною рамкою, а всередині в коментарі готовий тег `<img src="ВСТАВТЕ-URL-ФОТО" alt="…змістовний alt…" width=… height=…>`. Я завантажу фото кнопками в редакторі.
5. **Картка товару в тексті:** окремим рядком `<p>[[product:адреса-товару]]</p>` там, де доречно показати товар (адресу товару я дам). Ціни в тексті не пиши: сайт бере ціну з бази.
6. **FAQ:** розділ з `<h2>Часті запитання</h2>`, далі пари `<h3>питання</h3>` + `<p>відповідь</p>`. Сайт сам зробить із них розмітку для Google.
7. В кінці: темний блок «Висновок» з кнопкою, підпис «Більше, ніж просто речі ♡» і рядок джерел із посиланнями.
8. Посилання на категорії магазину: `/catalog/sport`, `/catalog/tech`, `/catalog/gifts`, `/catalog/style`, `/catalog/climate`, `/catalog/auto`. На товар: `/products/<адреса-товару>`.

Заборонено: `<script>`, `<iframe>`, `<style>`, форми, вигадані відгуки, рейтинги, «продано N разів», вигадані ціни та службові нотатки для мене всередині тексту статті.

---

## Як опублікувати (5 кроків)

1. Адмінка → **Статті** → **+ Нова стаття**.
2. Вставте весь HTML від Claude у поле **Текст статті**. Заголовок, адреса, анонс і SEO-поля заповняться самі — перевірте їх.
3. Під текстом зʼявиться список «Фото для статті»: натисніть **Завантажити** біля кожного.
4. Оберіть **Категорію** і **Головний товар** (для кнопки «Купити» на телефоні), натисніть **Як виглядатиме**.
5. Поставте **Опубліковано** → **Зберегти**. Щоб показати статтю на головній: **Блоки на головній** → «Що показує блок» → ваша стаття.
